## Project Overview
This project consists of a frontend and backend application built with React.js and Node.js.

## Prerequisites
- Node.js (v14 or higher)
- npm (Node Package Manager)

## Installation & Setup

### Backend Setup
1. Navigate to the backend directory:
   ```bash
   cd pharaohs-app/Backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the backend server:
   ```bash
   npm start
   ```
   The backend server will start running on http://localhost:5000

### Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd pharaohs-app/Frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the frontend development server:
   ```bash
   npm start
   ```
   The frontend application will start running on http://localhost:3000

## Running the Complete Application
1. Make sure to have both backend and frontend servers running simultaneously
2. Open your browser and navigate to http://localhost:3000
3. The application should now be running and ready to use

## Project Structure

## Troubleshooting
If you encounter any issues:
1. Ensure all dependencies are properly installed
2. Check if both servers are running
3. Clear your browser cache
4. Make sure no other applications are using ports 3000 or 5000
